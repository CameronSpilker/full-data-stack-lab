Tracking the health and growth of the open-source analytics ecosystem — the
tools this project is built with, measured with this project.

```sql latest
select max(week_start) as week_start from ecosystem_growth
```

```sql totals
select
    count(distinct tool_name) as tools_tracked,
    sum(stars) as total_stars,
    sum(contributor_count) as total_contributors,
    sum(weekly_downloads) as weekly_downloads
from ecosystem_growth
where week_start = (select max(week_start) from ecosystem_growth)
```

## Stars over time

```sql stars_over_time
select week_start, tool_name, stars
from ecosystem_growth
order by week_start
```

<LineChart data={stars_over_time} x=week_start y=stars series=tool_name title="Stars by tool" />

## Fastest growing

```sql fastest_growing
select tool_name, category, avg_star_growth_rate, stars
from tool_comparison
where avg_star_growth_rate is not null
order by avg_star_growth_rate desc
limit 10
```

<BarChart data={fastest_growing} x=tool_name y=avg_star_growth_rate title="Mean weekly star growth rate" swapXY=true />

## Everything tracked

```sql standings
select
    tool_name,
    category,
    stars,
    forks,
    contributor_count,
    weekly_downloads,
    category_rank_by_stars
from tool_comparison
order by stars desc
```
